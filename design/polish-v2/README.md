# Fotografías para tarjetas de dos columnas

Seis variantes de las fotografías generadas anteriormente. Editadas con la herramienta integrada de imágenes el 25 de noviembre de 2026 para que el sujeto quede más pequeño y completo a la derecha, con espacio para texto a la izquierda. No se cambia el número de tarjetas por fila. La variante de mockup de una sola columna se descartó por instrucción del usuario y no se entrega como referencia.

Los WebP conservan dimensiones y composición del resultado generado, optimizados de formato. Se abrieron y revisaron las seis imágenes y se verificó su decodificación. El encuadre final y el tamaño a pantalla deben comprobarse en la app con título y descripción reales. No se afirma que la corrección Kotlin ya esté hecha.

Conservar assets v1; cambiar únicamente los seis recursos de HomeCategory al implementar la corrección. Manifest.json lista rutas, tamaños y hashes reales. No dar a Claude una tarea de generar imágenes de nuevo: ya están aquí. La paleta y las rutas/funciones H2 no cambian.
